# Codex Collab Pair Marketplace

This repository is a Codex plugin marketplace containing **双对话协作 / Collab Pair**.

```bash
codex plugin marketplace add awa1231/codex-collab-pair
codex plugin add collab-pair@codex-collab
```

Version 2.1 is deliberately minimal: make the current conversation a project manager, let it create employee conversations, delegate tasks, and keep a persistent todo list. English is the default language. There is no task board, background server, or cross-device relay.

See [`plugins/collab-pair/README.md`](plugins/collab-pair/README.md) for full usage and verification instructions.
